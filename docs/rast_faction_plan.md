# План внедрения фракции «Rast жестянщики»

## Что уже подготовлено
- В `factions` добавлен отдельный ID спец-фракции `rastFactionId = 18`.
- Добавлен хелпер `isRastFaction(...)`.
- Добавлено ограничение: ящик `materialsBox` (металлолом/материалы) может сдавать только участник фракции Rast и только в склад своей фракции.

## Что нужно сделать дальше

1. **Создать фракцию в БД**
   - Добавить запись в таблицу `Factions` с `id = 18` и заполнить:
     - базовую точку фракции (`x/y/z/d`),
     - склад (`wX/wY/wZ/wD`),
     - точку выдачи (`sX/sY/sZ/sD`),
     - шкафы (`h*`, `ch*`),
     - гараж (`g*`) при необходимости,
     - стартовые лимиты `maxAmmo` (используется как склад материалов).
   - Добавить ранги в `FactionRanks` для `factionId = 18`.

2. **Добавить точки свалок (добыча металлолома)**
   - Рекомендуется отдельный пакет, например `packages/rastScrap`:
     - создать массив точек свалок;
     - на каждой точке создать marker + colshape;
     - при входе показывать prompt «Собрать металлолом»;
     - при активации выдавать игроку `materialsBox` (если руки свободны и нет другого ящика).

3. **Проверки доступа**
   - На сборе металлолома проверять:
     - игрок в фракции Rast (`factionId == 18`),
     - нет уже ящика в руках (`ammoBox/medicinesBox/materialsBox`),
     - cooldown на точку/игрока (чтобы не фармили мгновенно).

4. **Сдача на склад**
   - Уже реализовано на уровне `factions.putBox`: при сдаче `materialsBox` склад фракции пополняется.
   - При необходимости можно переименовать клиентские тексты интерфейса склада с «Боеприпасы» на «Материалы» именно для фракции `18`.

5. **Баланс**
   - Настроить:
     - `materialsBox` (сколько материалов даёт 1 ящик),
     - лимит склада `maxAmmo` для Rast,
     - время респауна металлолома на свалках,
     - число активных точек свалки.

## Минимальный MVP
1) Фракция ID 18 в БД.
2) 1 точка свалки с выдачей `materialsBox`.
3) Сдача в склад фракции (уже работает с ограничением доступа).
4) Проверка, что другие фракции не могут сдать металлолом.
